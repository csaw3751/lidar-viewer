Measure and analyse

Choose a tool and place points with the left mouse button. Right-click to finish a polyline, area, or profile.

Completing a profile opens the 2D analysis, which also provides CSV and LAS exports.

Clipping box

Clip places a box and shows only the points inside it. Use the coloured handles to move, rotate, and scale the box.

Advanced features

Details opens the complete Potree interface, rendering options, and GeoJSON or DXF export for measurement geometries.

Quality levels affect rendering only. High and Maximum display more points but require more data traffic, memory, and graphics performance.

Scan coordinates are local and measured in metres. No global coordinate reference system is defined.
